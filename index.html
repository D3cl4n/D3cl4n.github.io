Research Projects

zk-image-provenance

Github Repository

In this project, corresponding to the first listed publication, I am investigating using zero-knowledge proofs for verifying image provenance. I use a Raspberry Pi 4 with a camera module to emulate a camera that signs photos and their exifdata at capture time. The photos are then greyscaled and distributed to the verifier. This work uses a Halo2 zero-knowledge proof to convince the verifier that the original image (secret witness) hashes to the hash that was signed and that the only transformation applied to the original image was greyscaling. The verifier, given the edited image and the proof, verifies both the digital signature (using the camera's verifying key) and the proof, completing the chain of trust.

  • Goal: end-to-end prototype scaling to realistic image sizes
  • Methods: base256 encoding, Halo2, ECDSA, Poseidon
  • Current status: prototype finished, initial paper finished, future work identified

poseidon-rescue-halo2-benchmarking

Github Repository

In this work I implement a shared circuit construction for the Poseidon and Rescue-Prime permutations: POSEIDON^π and Rescue-XLIX. The shared construction provides a skeleton of common parameters and functionality, thus controlling confounding variables during benchmarking. Each permutation builds on the shared construction, completing its functionality. The comparative analysis of the low-level circuit metrics highlights design differences between the permutations. I analyze how these design differences affect low-level circuit metrics in Halo2 PLONKish circuits.

  • Goal: comparative analysis of arithmetic hash function design performance in PLONKish circuits
  • Methods: Poseidon, Rescue-Prime, Halo2
  • Current status: complete, paper published as Zenodo preprint (see above)
